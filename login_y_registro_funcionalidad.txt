Funcionalidad Unificada de Login y Registro

El sistema de autenticación de Harmonyapp se encarga de gestionar el ingreso, registro y seguridad de los usuarios de la plataforma.

1. Control de Acceso y Seguridad Compartida
-------------------------------------------------------------------
- Manejo de Sesiones Activas: Si un usuario ya tiene una sesión activa en el navegador, al intentar acceder a las pantallas de inicio de sesión o registro será redirigido automáticamente a la pantalla principal. No se permite registrarse o iniciar sesión si ya se está adentro del sistema.
- Seguridad de Contraseñas: Todas las contraseñas se almacenan de manera encriptada en la base de datos, garantizando que nunca se guarden en texto plano por motivos de seguridad.
- Cuentas Eliminadas: El sistema reconoce a los usuarios que han sido dados de baja. Esto asegura que los usuarios eliminados no puedan iniciar sesión ni interfieran si un nuevo usuario quiere registrarse con el mismo correo o nombre de usuario.

2. Funcionalidad de Registro
-------------------------------------------------------------------
- Datos Solicitados: Nombre, Apellido, Fecha de Nacimiento, Nombre de Usuario, Email y Contraseña.
- Proceso de Validación:
  - Ningún campo puede estar vacío.
  - Se valida que el correo electrónico no pertenezca a otra cuenta activa en el sistema.
  - Se valida que el nombre de usuario elegido no esté ya ocupado por otra persona.
- Resultado Exitoso: El sistema guarda de forma segura al nuevo usuario, lo habilita para su uso inmediato y lo redirige a la pantalla de inicio de sesión con un mensaje de confirmación que le avisa que ya puede ingresar.
- Resultado Fallido: Ante cualquier error (como un correo repetido o un campo vacío), la página se recarga mostrando el error detectado en pantalla para que el usuario pueda corregirlo.

3. Funcionalidad de Inicio de Sesión
-------------------------------------------------------------------
- Datos Solicitados: Email y Contraseña.
- Proceso de Validación:
  - Verifica que el usuario haya completado ambos datos.
  - Busca en el sistema si existe un usuario registrado con ese correo electrónico.
  - Verifica que la cuenta del usuario no esté desactivada o suspendida.
  - Comprueba de forma segura que la contraseña ingresada sea la correcta.
- Resultado Exitoso: El sistema reconoce al usuario, inicia su sesión de forma oficial y lo redirige a la pantalla principal de la aplicación.
- Resultado Fallido: Se deniega el acceso y la pantalla muestra el error correspondiente para guiar al usuario (por ejemplo, si el correo no existe o la contraseña es incorrecta).

4. Funcionalidad de Cierre de Sesión
-------------------------------------------------------------------
- Comportamiento: Se finaliza la sesión activa del usuario de manera completa y segura, borrando sus datos de acceso temporal y regresándolo a la pantalla principal de inicio de sesión.
